# Update the project to the latest version of kubebuilder

## Goal

Update the project to the latest version of kubebuilder.

## Steps

The workspace is already updated by `kubebuilder alpha update --force` command.

You need to resolve the conflicts. For example:

```
<<<<<<< HEAD
(This part is generated by kubebuilder)
=======
(This part is original)
>>>>>>> tmp-original-29-09-26-08-37
```

If both parts contain versions, keep the new version.

If not sure, prefer the original part.

## Verification

```bash
make fmt
make vet
make generate manifests
```
